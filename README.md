# Presentation Practice

Practice and present your PowerPoint talks. Upload the .pptx (notes + timing) and its PDF export (slide visuals). Everything runs in your browser; nothing is uploaded anywhere.

## Features
- Notes check, timer, per-slide time targets, and a post-run analysis.
- Library: keeps up to 5 decks (notes + PDF) in this browser, so you don't re-upload on presentation day. Uploading a file with the same name replaces the saved copy.
- Offline: after one visit with internet, the app (and its PDF/PowerPoint libraries) opens without internet on that device. The line at the bottom of the page says "Offline ready" when it is set up.
- Keeps the screen awake during a run, and shows whether the projector window is connected and fullscreen.
- Clicker keys: Page Down / Page Up, arrow keys, space or Enter = next/back; "." or B = blank projector. Type a slide number then Enter to jump, G opens the slide list, L goes back to the last slide you were on.
- Present mode: a projector window shows the slide full screen while your laptop window shows notes, next slide and timer.

## Present mode on the day
1. Connect the projector and set the display to Extend.
2. Open the app, tap Use on your saved deck, then Present (two windows). Allow pop-ups if asked.
3. Drag the projector window to the projector screen, then click it or press F for fullscreen.
4. Advance slides from the laptop window (arrow keys, space, or a clicker). Press B to blank the projector.
Both windows must be in the same browser. Slides on the projector come from your PDF, so animations and videos do not play.

## Put it on GitHub Pages
1. Create a new repository and upload all files in this folder (index.html, sw.js, manifest.webmanifest, icons/, README.md) to the repo root.
2. Go to Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, then Save.
3. Open `https://<your-username>.github.io/<repo-name>/` after a minute or two.

## Before presentation day
1. Open the GitHub Pages link on the presenting laptop, with internet, and reload once. Check the bottom of the page says "Offline ready".
2. Tap Use on your deck, then Present, and test the projector window and your clicker.
3. Use the same browser on the day. Saved decks and offline files live in that browser.

## Add to iPhone home screen
Open the page in Safari, tap Share, then Add to Home Screen. (Present mode is meant for a laptop.)
